# Лабораторная работа 9 - Директивы оператора

Вариант 14. C# / .NET 10. Внешних пакетов нет.
Модель одного CPU: RR, относительные и динамические приоритеты, три очереди Q0–Q2. Большие по памяти задания получают больший базовый приоритет.

```powershell
dotnet build MeiOS.Lab09.sln
dotnet run --project src
dotnet run --project src -- /?
dotnet run --project src -- --ticks 100 --seed 14
dotnet run --project src -- --ticks 100 --seed 14 --width 180 --height 48
dotnet run --project src -- --config src/params.txt --ticks 100 --seed 14
dotnet run --project src -- --ticks 2000 --script example-operators.txt --seed 14
dotnet run --project src -- --self-test
dotnet run --project src -- --benchmark 5 --speed 100
```

Клавиши: Q выход, +/- изменение скорости на 10%, R перезапуск, H справка.
Для текстовой команды нажмите : и введите команду, затем Enter. Доступные команды выводит /?.
Экран обновляется на месте и подстраивается под окно. F1 — модель, F2 — детали, F3/H — справка.
PgUp/PgDn — прокрутка; Esc — отмена ввода. Управление закреплено внизу.
Компактный режим — 80x24; широкий полный вывод ЛР6-9 — например, 180x48.
--ticks выполняет моделируемые такты без реальной задержки. --benchmark использует реальные часы и тот же цикл управления временем.

Параметры читаются один раз из params.txt рядом с программой; при сборке файл копируется автоматически. Строка: key min max step пояснение; # начинает комментарий. Диапазоны разрешены для всех параметров. Системные значения выбираются при инициализации, параметры заданий — при создании каждого задания. Reset восстанавливает seed без повторного чтения файла.

Числа word: 0..65535. Обратные границы упорядочиваются, нулевой шаг заменяется единицей. Границы приводятся к области параметра с сообщением: память и размеры положительные, IO 0..100, PSW 1..16. Значение выбирается на сетке min + k * step и не превышает max.

Директивы: task size count ioPercent, auto off/on, load, suspend id, resume id, kill id, drain, memory size. Count задаёт число команд до дополнительного Exit. ID вводится числом без P. Suspend разрешена для Ready/Active; resume возвращает процесс в Ready. Load ждёт освобождения CPU. Drain запрещает новые поступления и останавливает модель после завершения резидентов; при Suspended сначала выполните resume или kill. Память нельзя уменьшать ниже занятого объёма.

Сценарий example-operators.txt содержит строки такт|директива. Параметр --script работает вместе с --ticks. Ключ --seed задаёт последовательность генератора; по умолчанию 14.
